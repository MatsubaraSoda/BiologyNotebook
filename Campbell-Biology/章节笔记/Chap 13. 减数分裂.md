# 减数分裂

## 动物细胞减数分裂

1. 第一次减数分裂：分离同源染色体
   1. 前期
      1. 中心体移动、纺锤体形成以及核膜破裂的过程与有丝分裂相同。染色体在前期期间逐渐凝缩。
      2. 在前期的早期，每条染色体都会与其同源染色体配对，基因与基因逐一对齐，并发生**交叉互换**：非姐妹染色单体的DNA分子在蛋白质的作用下发生断裂，并重新连接到彼此。
      3. 每个同源对都有一个或多个呈X形的的区域，称为交叉点，交叉互换正是在这些区域中发生的。
      4. 前期的后半段，来自某一极或另一极的微管会附着在动粒上，每个同源染色体的着丝粒处各有一个动粒。（同源染色体姐妹染色单体上的两个动粒由蛋白质连接在一起，共同作用如同一个单一的动粒。）微管将同源对移向赤道板。
   2. 中期
      1. 同源染色体对现在排列在赤道板上，每对中的一条染色体面向每一极。
      2. 每对染色体都独立于其它对排列（这种排列方式被称为独立分配）。
      3. 同一个同源染色体的两条染色单体都连接来自同一极的动粒微管；而另一个同源染色体的两条染色单体则连接来自相反极的微管。
   3. 后期
      1. 沿染色体臂负责姐妹染色单体黏连的蛋白质发生降解，使同源染色体得以分离。
      2. 同源染色体在纺锤体的引导下移向相对的两极。
      3. 姐妹染色单体黏连在着丝粒处得以维持，导致每条染色体的两条染色单体作为一个整体向同一极移动。
   4. 末期与胞质分裂
      1. 当减数分裂末期开始时，细胞的每一半都拥有一套完整的单倍体组复制的染色体。每条染色体由两条姐妹染色单体组成；其中一条或两条染色单体包含非姐妹染色单体DNA区域。
      2. 胞质分裂通常与减数分裂末期同时发生，形成两个单倍体子细胞。
      3. 在动物细胞中，会形成裂沟。（在植物细胞中，则形成细胞板。）
      4. 在某些物种中，染色体会去凝聚并形成核膜。
      5. 在第一次减数分裂和第二次减数分裂之间不发生染色体复制。
2. 第二次减数分裂：分离姐妹染色单体
   1. 前期
      1. 纺锤体形成。
      2. 在前期的后半段，染色体仍由两个在着丝粒处连接的染色单体组成，微管将其移向第二次减数分裂中期的赤道板。
   2. 中期
      1. 染色体位于赤道板，与有丝分裂相同。
      2. 由于第一次减数分裂中的交叉互换，每条染色体的两条姐妹染色单体在基因型上并不相同。
      3. 姐妹染色单体的动粒与从相对两极延伸出的微管相连。
   3. 后期
      1. 位于着丝粒处、将姐妹染色单体连接在一起的蛋白质发生分解，使得染色单体得以分离并移向相对两极。此时，每条染色单体已成为一条独立的染色体。
   4. 末期与胞质分裂
      1. 细胞核形成，染色体开始去浓缩，胞质分裂发生。
      2. 一个母细胞的减数分裂产生四个子细胞，每个子细胞都含有一组单倍体（未复制的/单链的）的染色体。
      3. 这四个子细胞彼此之间以及与母细胞在遗传上各不相同。

## 同源染色体联会与交叉互换

1. 基因对齐与DNA断裂
   在第一次减数分裂前期的早期，同源染色体（一条来自父本，一条来自母本，此时都已经复制成两条姐妹染色单体）开始沿着长度方向松散地并排靠拢。
   它们会做到基因级别的一一对应。此时，特定蛋白质会在非姐妹染色单体（一条父方、一条母方）的精确对应位置上，并制造出DNA双链断裂。
2. 联会复合体形成
   接下来，同源染色体之间会开始形成一种类似“拉链”的蛋白质结构，称为联会复合体。
   联会复合体将两条同源染色体像拉拉链一样紧紧地“锁”在一起。当这种紧密连接完成时，我们称之为处于联会状态。
3. 完成交叉互换
   真正的“互换”发生在联会状态下。之前在第一步被切断的DNA末端，此时会被重新连接。
   断裂的末端并不会接回原来的染色单体上，而是交叉连接到非姐妹染色单体的对应片段上。结果就是，一段父本DNA物理上拼接到了母本的DNA单体上（反之亦然），完成了遗传物质的重组。
4. 复合体解体与交叉点显现
   交叉互换完成后，起固定作用的联合复合体开始降解，同源染色体稍微互相分离。
   此时它们并没有完全分开。在发生过交叉互换的物理位置，染色体会依然保持连接，形成肉眼或显微镜下可见的"X"型交叉结构，称为交叉点（Chiasmata）。它们会靠着交叉点和姐妹染色单体间的凝聚素保持连结，直到第一次减数分裂后期才会被主轴丝拉开。
