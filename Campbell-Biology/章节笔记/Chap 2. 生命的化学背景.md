## 人体内的元素

| Element    | Symbol | Percentage of Body Mass (including water) |
| ---------- | ------ | ----------------------------------------- |
| Oxygen     | O      | 65.0%                                     |
| Carbon     | C      | 18.5%                                     |
| Hydrogen   | H      | 9.5%                                      |
| Nitrogen   | N      | 3.3%                                      |
| Calcium    | Ca     | 1.5%                                      |
| Phosphorus | P      | 1.0%                                      |
| Potassium  | K      | 0.4%                                      |
| Sulfur     | S      | 0.3%                                      |
| Sodium     | Na     | 0.2%                                      |
| Chlorine   | Cl     | 0.2%                                      |
| Magnesium  | Mg     | 0.1%                                      |
