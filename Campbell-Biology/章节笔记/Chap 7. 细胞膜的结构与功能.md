

# 被动运输

```
被动运输：顺梯度，不直接消耗ATP
├── 简单扩散：直接穿过磷脂双层
├── 协助扩散：通过通道蛋白或载体蛋白
└── 渗透：水的跨膜净移动

主动运输：逆梯度，需要能量
├── ATP直接驱动的泵
└── 利用另一种物质梯度的协同运输
```

## 渗透压

### “高”和“低”如何判断

> 当膜只允许水通过、不允许某种溶质通过时，水会从溶质较少的一侧，净移动到溶质较多的一侧。

假设半透膜两侧分别是：
- A侧：1% 蔗糖溶液
- B侧：10% 蔗糖溶液
- 膜允许水通过，但不允许蔗糖通过

那么：

| 比较对象               | A侧：1%蔗糖 | B侧：10%蔗糖 |
| ---------------------- | ----------: | -----------: |
| 溶质浓度               |          低 |           高 |
| 可自由运动的水相对多少 |          多 |           少 |
| 渗透压                 |          低 |           高 |
| 水势                   |          高 |           低 |
| 水的净移动方向         |       A → B |       接收水 |

### 渗透压的严格含义

> 为了阻止纯水或较稀溶液中的水通过半透膜进入较浓浓度，需要在较浓溶液一侧施加的压力。

稀溶液中近似满足：
$$
\pi = i C R T
$$
其中：

- $\pi$ : 渗透压
- $i$ : 溶质解离产生的粒子数因子
- $C$ : 溶质粒子的摩尔浓度
- $R$ : 气体常数
- $T$ : 绝对温度



### 水势的方向相反

> 水从较高处向较低处净移动。

简化表示：
$$
\Psi = \Psi_s + \Psi_p
$$

- $\Psi_s$ : 溶质势，溶质越多，它越低、越负
- $\Psi_p$ : 压力势，物理压力越大，它通常越高

纯水在标准条件下的水势规定为0。加入溶质后，水势会下降，例如可能变成 $-0.5\ \text{MPa}$。

因此：

- 纯水：$\Psi = 0$
- 糖水：$\Psi < 0$
- 水从 $0$ 流向 $-0.5\ \text{MPa}$



### 植物细胞为什么在低渗环境中反而状态良好

动物细胞没有细胞壁，在低渗溶液中吸水过多可能破裂。

植物细胞吸水后：

1. 液泡和细胞膨胀；
2. 细胞膜向外挤压细胞壁；
3. 细胞壁产生反向压力；
4. 压力势升高，最终抵消继续吸水的趋势。

这时细胞处于**膨压充足**的状态，通常是植物细胞的正常、健康状态。

植物细胞在不同环境中的表现：

- 低渗环境：吸水，膨压增大，细胞坚挺
- 等渗环境：膨压不足，细胞可能松弛
- 高渗环境：失水，细胞膜与细胞壁分离，发生质壁分离



### 选择性渗透膜

**不同物质穿膜的难易程度**

一般规律如下：

| 物质类型             | 直接穿过磷脂双层     | 例子               |
| -------------------- | -------------------- | ------------------ |
| 小型非极性分子       | 容易                 | O₂、CO₂、N₂        |
| 疏水性分子           | 较容易               | 类固醇激素         |
| 很小的不带电极性分子 | 可以，但速度不一定快 | H₂O、尿素、甘油    |
| 较大的极性分子       | 很困难               | 葡萄糖、蔗糖       |
| 离子                 | 几乎不能直接通过     | Na⁺、K⁺、Ca²⁺、Cl⁻ |
| 大分子               | 不能直接通过         | 蛋白质、DNA、多糖  |

决定通透性的关键因素主要是：

- 是否带电
- 极性强弱
- 分子大小
- 脂溶性
- 膜上是否存在对应的通道或转运蛋白

其中，**电荷通常是很强的阻碍**。离子在水中会被水分子包围，形成水合层。它们若进入膜的疏水核心，就需要摆脱这种稳定状态，能量代价很高。因此，即使Na⁺和K⁺很小，也不能轻易直接穿膜。

**磷脂双层天然阻挡大多数离子和亲水溶质；水因为分子很小，可以有限地穿过，而生物膜通常借助水通道蛋白显著提高水的通透性。**





### 张性，溶液的渗透性 Tonicity

在《坎贝尔生物学》的入门例子中，通常会暂时假定溶质不能穿过膜。在这种简化条件下，渗透浓度与张性的判断通常一致。

> 一种溶液使细胞获得水或失去水，从而改变细胞体积的能力。

更直观地说，tonicity 回答的是：

> **把细胞放进这种溶液后，细胞最终会膨胀、皱缩，还是体积基本不变？**

它是**外界溶液相对于某个细胞**的性质，不能脱离细胞和细胞膜单独判断。

### 动物细胞与植物细胞

Tonicity对动物细胞和植物细胞的影响不同，因为植物细胞有细胞壁。

#### 动物细胞

- 低张液：吸水膨胀，可能裂解
- 等张液：体积稳定，通常较合适
- 高张液：失水皱缩

例如，哺乳动物红细胞通常需要处于接近等张的环境中。

#### 植物细胞

- 低张液：吸水，产生膨压，细胞坚挺，通常是理想状态
- 等张液：没有足够膨压，细胞较松弛
- 高张液：失水，细胞膜可能脱离细胞壁，发生质壁分离

植物细胞在低张环境中通常不会轻易破裂，因为坚硬的细胞壁会产生反向压力，限制其继续膨胀。

因此，《坎贝尔生物学》中常见的结论是：

> 动物细胞通常适合等张环境；植物细胞通常在低张环境中状态较好。

低张液：水进细胞，细胞变大；
等张液：无净移动，体积稳定；
高张液：水出细胞，细胞变小。

## 协助扩散 Facilitated diffusion

> 物质借助细胞膜上的运输蛋白，沿着自身的浓度梯度或电化学梯度跨膜移动，并且不直接消耗细胞能量。

### 与简单扩散的区别

两者都属于**被动运输（passive transport）**：

| 特征            | 简单扩散           | 协助扩散         |
| --------------- | ------------------ | ---------------- |
| 是否需要膜蛋白  | 不需要             | 需要             |
| 是否顺梯度      | 是                 | 是               |
| 是否直接消耗ATP | 否                 | 否               |
| 典型物质        | O₂、CO₂、类固醇    | 离子、葡萄糖、水 |
| 是否具有选择性  | 主要由分子性质决定 | 由运输蛋白决定   |
| 是否可能饱和    | 通常不明显         | 载体介导时明显   |

### 两类运输蛋白

协助扩散主要通过两类蛋白质完成。

#### 1. 通道蛋白

**通道蛋白（channel protein）**在膜中形成一条亲水通道，允许符合条件的粒子通过。

常见例子包括：

- 水通道蛋白 aquaporin
- K⁺通道
- Na⁺通道
- Cl⁻通道

通道通常具有选择性。一个K⁺通道不意味着所有小离子都能通过；通道内部的结构会根据离子大小、电荷以及与通道中氨基酸的相互作用筛选粒子。

很多离子通道还可以开关：

- **电压门控通道**：受膜电位变化控制
- **配体门控通道**：某种分子结合后打开或关闭
- **机械门控通道**：受拉伸、压力或振动控制

通道打开以后，离子仍然是沿着自己的电化学梯度移动，并不是通道蛋白主动“把它推过去”。

#### 2. 载体蛋白

**载体蛋白（carrier protein）**会先与特定溶质结合，然后改变自身构象，将溶质释放到膜的另一侧。

简化过程：溶质结合 ➡ 载体改变形状 ➡ 溶质在另一侧释放 ➡ 载体恢复原状

葡萄糖转运蛋白GLUT是典型例子。葡萄糖与载体结合后，载体改变构象，使葡萄糖到达膜的另一侧。

载体不是一条始终开放的孔道。它每次通常只能运输有限数量的分子，因此速度比许多通道慢，并且容易出现**饱和现象**。

####  沿浓度梯度

假设细胞膜外葡萄糖浓度高，膜内葡萄糖浓度低，而且膜上有对应的GLUT转运蛋白：

```
细胞外：葡萄糖多
        ↓ 协助扩散
细胞内：葡萄糖少
```

葡萄糖净移动方向为外到内。

如果条件反过来，细胞内游离葡萄糖更多，那么同一种转运蛋白原则上也可能使葡萄糖净移动到细胞外。协助扩散的方向由梯度决定，而不是由蛋白质固定指定。

#### 电化学梯度

对不带电分子，例如葡萄糖，在入门模型中主要比较浓度。

对于Na⁺、K⁺、Cl⁻等离子，仅比较浓度不够，因为离子同时受到两种作用：

1. **化学梯度**：倾向于从高浓度处向低浓度处移动
2. **电梯度**：正离子被负电一侧吸引，负离子被正电一侧吸引

两者合在一起叫作**电化学梯度（electrochemical gradient）**。

例如，某个细胞中：

- 细胞外Na⁺浓度高
- 细胞内Na⁺浓度低
- 细胞内部相对于外部带负电

那么：

- 浓度差推动Na⁺进入细胞
- 电位差也吸引Na⁺进入细胞

当Na⁺通道打开时，Na⁺会迅速进入细胞。这个过程仍然是协助扩散，不直接消耗ATP，因为Na⁺是在顺电化学梯度移动。

#### 不消耗ATP，不等于不涉及能量

协助扩散不需要ATP水解来直接推动运输，但这不表示它“完全没有能量”。

扩散的驱动力来自物质已经存在的浓度梯度或电化学梯度。例如Na⁺进入细胞时，是在释放其梯度中储存的势能。

而这个梯度往往是由其他主动运输蛋白提前建立的。例如：

1. 钠钾泵消耗ATP，把Na⁺泵出细胞
2. 细胞外因此积累较多Na⁺
3. Na⁺通道打开
4. Na⁺通过通道顺梯度进入细胞

其中：

- 钠钾泵：**主动运输**
- Na⁺通过通道进入：**协助扩散**

所以判断某个具体跨膜步骤是否属于协助扩散，应看该步骤本身是否顺梯度、是否由梯度驱动。



## 主动运输

### 生电泵 (electrogenic pump)

> 生电泵是指在主动运输过程中，跨膜移动的正、负电荷不完全抵消，从而产生或维持膜两侧电位差的运输蛋白。

钠钾泵是典型的生电泵：每轮运输将3个Na⁺泵出细胞、将2个K⁺泵入细胞，净移出1个正电荷。

并非所有主动运输蛋白都是生电泵。只有当一次运输的净电荷发生跨膜移动时，才称为“生电”。

#### 对生电泵的认识历史：先发现功能，后看见结构

生物学家对生电泵的认识，并不是从显微镜直接观察一个泵开始的，而是经历了“观察生物电现象 → 推断主动运输 → 找到泵蛋白 → 解析结构”的过程。

1. **发现生物电现象**

   18世纪，伽伐尼研究蛙腿抽动，提出动物组织存在“动物电”。当时还不知道细胞膜和离子泵，只是观察到生物组织与电有关。

2. **测量到膜电位**

   19世纪末至20世纪上半叶，研究者借助电极和微电极发现，许多静息细胞的膜内相对于膜外带负电。此时已知细胞膜两侧存在电位差，但还不知道其完整成因。

3. **证明离子存在逆梯度运输**

   20世纪40至50年代，研究者利用放射性同位素追踪Na⁺、K⁺等离子的跨膜移动，发现细胞能持续排出Na⁺、摄入K⁺；抑制ATP供应后，这种运输会减弱或停止。这表明细胞膜上存在消耗能量的主动运输机制。

4. **确认具体的泵蛋白**

   1957年，Jens Skou发现Na⁺/K⁺-ATPase（钠钾泵）。这种膜蛋白能水解ATP，并与Na⁺和K⁺的运输相联系，提供了主动运输由特定蛋白质完成的直接生化证据。

5. **建立运输循环模型并解析结构**

   后续实验揭示，钠钾泵会在结合离子、被ATP磷酸化、改变构象、释放离子和去磷酸化之间循环。随着X射线晶体学和冷冻电镜的发展，研究者才逐渐获得泵蛋白不同构象的三维结构。

#### 为什么不靠普通显微镜直接发现它

- 脂质双层厚度约为几纳米，单个膜蛋白也处于纳米尺度；普通光学显微镜的分辨率约为200 nm，无法分辨单个泵。
- 即使电子显微镜能够显示膜的精细结构，也难以直接记录单个泵在运输过程中的动态构象变化。
- 但是，泵造成的后果可以在更大尺度测量：膜电位、离子浓度变化、ATP消耗和离子通量都能提供证据。

因此，生电泵的认识路径是：

> 测到膜电位和离子运输现象 → 推断存在主动机制 → 通过生化实验找到泵蛋白 → 借助结构生物学观察其构象。



### 钠钾泵

#### 认识过程：Na⁺和K⁺为何被认为是膜电位的关键离子

对钠钾泵的理解，建立在更早的一条研究线索上：科学家先发现外界离子能改变细胞的电活动，随后才逐步确认K⁺和Na⁺在膜电位中的不同作用，最后才找到维持二者浓度梯度的钠钾泵。

1. **早期观察：改变外液离子会改变组织活动**

   19世纪80年代，Sydney Ringer研究蛙心时发现，灌流液中Na⁺、K⁺和Ca²⁺的组成会显著影响心脏跳动。这一时期还没有“离子通道”或“离子泵”的概念，但实验已经表明：细胞的电活动与周围离子有关。

2. **K⁺被提出为静息膜电位的主要来源**

   1902年前后，Julius Bernstein提出膜理论。他认为静息细胞膜对K⁺比对其他离子更容易通透；由于细胞内K⁺浓度较高，K⁺有向外扩散的趋势，细胞内则留下相对更多不可自由跨膜的负电荷，于是膜内相对于膜外带负电。

   这一理论的核心不是“K⁺是唯一的离子”，而是：**静息状态下，膜对哪种离子的通透性最高，哪种离子就最能影响膜电位。**在许多动物细胞中，这种离子是K⁺。

3. **动作电位的正相位提示Na⁺内流**

   1939年，Alan Hodgkin和Andrew Huxley发现，神经冲动的峰值可超过0 mV，即细胞内短暂变得相对膜外为正。单靠K⁺外流无法解释这一现象；它提示有正离子迅速进入细胞，而Na⁺是最可能的候选。

4. **离子替换实验加强了Na⁺假说**

   20世纪40年代末，研究者改变细胞外Na⁺浓度，发现动作电位峰值会随之改变，并接近Na⁺的平衡电位。这支持了“动作电位上升期主要由Na⁺内流造成”的解释。

5. **电压钳实验给出定量证据**

   1952年，Hodgkin和Huxley利用枪乌贼巨轴突进行电压钳实验，定量描述了动作电位中的离子电流：

   - 去极化上升期：Na⁺通透性迅速升高，Na⁺主要向内流动；
   - 复极化和恢复期：K⁺通透性升高，K⁺主要向外流动。

   因而，Na⁺和K⁺被确立为神经细胞膜电位变化中最关键的离子。静息膜电位通常主要受K⁺漏通透性影响；Na⁺则在动作电位的快速去极化中尤其重要。

6. **找到维持Na⁺、K⁺梯度的机制：钠钾泵**

   上述离子流动会逐渐消耗浓度梯度，因此还需要一种机制长期维持“细胞外Na⁺高、细胞内K⁺高”的状态。1957年，Jens Skou发现Na⁺/K⁺-ATPase，即钠钾泵。它将ATP水解与Na⁺外排、K⁺内运相联系，补全了离子梯度如何长期维持的解释。

> 历史上的认识顺序：外液离子影响细胞活动 → K⁺被提出为静息膜电位的主要影响因素 → Na⁺内流解释动作电位上升 → 电压钳定量验证Na⁺、K⁺电流 → 发现钠钾泵维持两种离子的梯度。

#### 坎贝尔第七章的核心知识

- 钠钾泵是**由ATP直接驱动的主动运输蛋白**，也是载体蛋白。
- 每个循环通常将**3个Na⁺泵出细胞**，并将**2个K⁺泵入细胞**；二者均逆各自的电化学梯度运输。
- ATP使泵蛋白发生磷酸化和构象改变；结合K⁺后去磷酸化，泵恢复原构象并将K⁺释放到细胞内。
- 每轮净移出1个正电荷，因此钠钾泵是**生电泵**，有助于维持膜电位和Na⁺、K⁺浓度梯度。
- Na⁺通过开放的通道顺梯度进入细胞是协助扩散；钠钾泵把Na⁺逆梯度泵出则是主动运输。



### 质子泵

#### 认识过程：从pH到质子电化学梯度

质子泵的认识经历了“先能测量H⁺ → 发现膜两侧有质子梯度 → 证明梯度能做功 → 找到具体泵蛋白”的过程。

1. **酸、碱和pH提供了测量工具**

   19世纪末至20世纪初，化学家逐渐建立了酸、碱和氢离子的理论。1909年，Sørensen提出pH概念，使研究者能够定量描述溶液中H⁺的多少。此时还没有生物学上的质子泵，但pH测量为追踪H⁺跨膜移动提供了方法。

2. **呼吸和ATP合成的联系仍然不清楚**

   20世纪上半叶，研究者已经知道线粒体呼吸会释放能量，并且这种能量与ATP合成有关。但当时还不清楚电子传递、跨膜运输和ATP合成之间的具体联系，常被设想为呼吸释放的能量直接用于合成ATP。

3. **Mitchell提出化学渗透学说**

   1961年，Peter Mitchell提出：电子传递链释放的能量可以用来把H⁺泵到膜的一侧，形成质子电化学梯度；H⁺随后顺梯度回流，通过ATP合酶驱动ATP合成。

   ```
   电子传递链：能量 → H⁺被泵过膜 → 形成质子梯度
   ATP合酶：H⁺顺梯度回流 → 驱动ATP合成
   ```

   这一观点最初受到争议，因为它不依赖一个传统意义上的“高能中间化合物”，而是把跨膜梯度本身看作能量储存形式。Mitchell最终因化学渗透学说于1978年获得诺贝尔化学奖。

4. **pH跳变实验证明质子梯度能够做功**

   1966年，Jagendorf和Uribe对叶绿体进行经典实验：先让叶绿体内部积累H⁺，再迅速改变外界环境。即使没有立即进行完整的光反应，只要H⁺梯度存在，叶绿体也能短时间合成ATP。

   这说明质子梯度不是呼吸或光合作用的附带现象，而是能够直接驱动ATP合成的能量来源。线粒体和细菌膜中的类似实验随后支持了这一结论。

5. **发现不同类型的质子泵**

   后续研究表明，“质子泵”不是一种单独的蛋白，而是一大类能够主动运输H⁺的蛋白质：

   - **呼吸链中的质子泵**：线粒体电子传递链的复合体I、III、IV利用电子传递释放的能量，把H⁺泵入膜间隙。
   - **光驱动质子泵**：例如细菌视紫红质，利用光能把H⁺泵过膜。
   - **V型质子泵**：把H⁺泵入溶酶体、液泡等细胞器，使其内部酸化。
   - **植物质膜H⁺-ATPase**：消耗ATP把H⁺泵出细胞，建立跨膜梯度，并为其他离子的协同运输提供驱动力。

6. **现代结构研究揭示工作方式**

   膜泡实验、蛋白质纯化、X射线晶体学和冷冻电镜逐渐显示，质子泵会结合H⁺，利用ATP水解、电子传递或光能改变构象，在膜的另一侧释放H⁺，通过循环不断建立质子梯度。

> 历史上的认识顺序：能够测量pH → 发现呼吸和ATP合成有关 → 提出质子梯度假说 → pH跳变实验证明梯度能驱动ATP合成 → 找到并解析不同的质子泵。

#### 坎贝尔第七章的核心知识

- 质子泵是主动运输蛋白，能把H⁺逆电化学梯度泵过膜。
- 它建立的是**质子电化学梯度**，包括H⁺浓度差和膜电位差。
- H⁺顺梯度回流可以驱动ATP合成，也可以驱动另一种物质的协同运输。
- 质子泵使用的能量来源可以是ATP水解、电子传递或光能，具体取决于泵的类型。

## 胞吐与胞吞

胞吐和胞吞是**大宗运输（bulk transport）**：细胞通过形成、运输或融合囊泡，整体运输大分子、大颗粒或一部分细胞外液，而不是让物质逐个直接穿过磷脂双层或运输蛋白。

### 认识发展历程：从观察细胞行为到解析囊泡运输机器

对胞吐和胞吞的认识经历了“观察到细胞吞入或分泌物质 → 观察到膜和囊泡的形态变化 → 证明选择性摄取 → 找到调控囊泡形成和融合的蛋白质”的过程。

1. **最早观察到细胞能够吞入大颗粒**

   19世纪后期，Ilya Metchnikoff观察到某些活动细胞会伸出伪足，包围并摄入异物、微生物或细胞碎片。19世纪80年代，他提出这类吞噬细胞能够保护机体，奠定了细胞免疫的重要思想。

   当时能够在显微镜下看到细胞“包住”颗粒，但还不知道这是一种由质膜形变形成囊泡的过程，也不知道其中涉及受体和细胞骨架。

2. **胞饮被认识为细胞对外界液体的摄入**

   20世纪初，研究者发现许多细胞会不断摄入小滴细胞外液。Warren Lewis在1931年前后使用了“胞饮（pinocytosis）”一词，字面意思是“细胞饮水”。

   后来，染料和示踪分子实验表明，胞饮并非主要为了让水进入细胞；水可通过渗透和水通道直接跨膜。胞饮的特点是把**水和其中不能自由跨膜的溶质整体包入囊泡**。

3. **电子显微镜使“膜内陷形成囊泡”可见**

   20世纪中期，电子显微镜显示，被摄入的颗粒或液体处在由膜包围的囊泡中；囊泡可进一步与溶酶体融合，内容物被处理或分解。由此，吞噬和胞饮被统一理解为胞吞（endocytosis）的不同形式。

4. **分泌细胞研究建立了胞吐模型**

   人们早已知道腺体细胞会分泌酶、黏液和激素，但并不清楚这些大分子如何离开细胞。20世纪50年代，George Palade等人利用电子显微镜和脉冲追踪实验研究胰腺腺泡细胞，逐步描绘出分泌蛋白从粗面内质网，经高尔基体进入分泌囊泡，再释放到细胞外的路径。

   分泌囊泡贴近并与质膜连续的图像，支持了胞吐（exocytosis）模型：囊泡膜与质膜融合，囊泡内容物释放到细胞外，囊泡膜则并入质膜。

5. **神经递质的“量子释放”支持囊泡胞吐**

   20世纪中期，Bernard Katz等人研究神经肌肉接头，发现神经递质以离散的“量子”而非连续流的形式释放。后续实验表明，Ca²⁺进入突触前末梢会触发突触囊泡与质膜融合，使神经递质通过胞吐释放。

6. **遗传性高胆固醇血症揭示受体介导胞吞**

   20世纪70年代，Michael Brown和Joseph Goldstein研究遗传性高胆固醇血症时发现，某些患者的细胞不能正常摄取LDL（low-density lipoprotein，低密度脂蛋白）。

   他们证明：LDL先与细胞表面的LDL受体结合；受体集中在特定的膜内陷区域；这些区域形成囊泡，将LDL带入细胞。受体异常会降低LDL摄取，并使血液胆固醇升高。这建立了**受体介导的胞吞（receptor-mediated endocytosis）**的经典模型。

7. **从囊泡形态进入分子机制阶段**

   随后的研究发现，网格蛋白等包被蛋白可帮助膜弯曲并集中受体与货物；一些蛋白参与囊泡从质膜切断；另一些膜融合蛋白使囊泡与特定目标膜融合。2013年诺贝尔生理学或医学奖表彰了对囊泡运输调控机制作出重要贡献的研究，反映出人们已从“看见囊泡”进入“理解囊泡如何被精确调控”的阶段。

> 历史上的认识顺序：观察吞噬和胞饮 → 电子显微镜看见膜内陷与囊泡 → 分泌细胞研究建立胞吐模型 → LDL受体研究证明选择性胞吞 → 解析囊泡形成、切断和融合的分子机制。

### 坎贝尔第七章的核心知识

- **胞吐**：囊泡与质膜融合，内容物释放到细胞外，囊泡膜并入质膜；常用于分泌蛋白质、神经递质和补充质膜成分。
- **胞吞**：质膜内陷并形成囊泡，将细胞外物质带入细胞；囊泡腔内的液体起初仍与细胞质基质隔着一层膜。
- 胞吞包括三种常见形式：**吞噬**摄入大颗粒；**胞饮**摄入细胞外液及溶质；**受体介导的胞吞**借助特异性受体选择性摄取分子。
- 胞吐和胞吞通常需要能量，并共同调节质膜面积、膜成分及细胞与环境之间的物质交换。
